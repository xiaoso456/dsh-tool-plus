# unxz

| 项 | 内容 |
|---|---|
| 一句话定位 | 解压 `.xz`，等价于 `xz -d` |
| 实现层 | 内建命令；与 `xz`、`xzcat` 共用一份实现（`xzcmd.rs`），本文件只记录该调用名的差异 |
| 与 xz 的差异 | 隐含 `-d`；其余参数与限制一致 |
| 完整能力面 | 见 [xz.md](./xz.md) |
| 测试 | `cargo test -p pi-builtins xzcmd` 覆盖（同一实现） |

## 为什么共用一个实现

GNU XZ Utils 也是同一可执行文件按 `argv[0]` 切换默认行为；三个名字参数集合相同，只差默认值，拆开只会让逻辑漂移。

## 局限

与 [xz.md](./xz.md) 相同（单线程、无块控制、只支持 xz 容器）。
