# SWE-bench Multilingual · 三种工具面运行对比（deepseek-v4.1-flash）

> 同一个模型、同一批题、同一个驱动器，只换工具面与调用模式。三轮已全部完成，本稿为 VM 时间 2026-11-25 08:40 的完整快照。

## 1 实验条件

| 项 | 值 |
|---|---|
| 数据集 | SWE-bench Multilingual，首批 20 题抽样（Rust / Java / Go / TypeScript 为主，含 feature 类）|
| 题量 | 每组每轮 20 题 |
| harness | DSH 0.2.2-rc.5 + Node 24.22.3 |
| 模型 | deepseek-v4.1-flash:1017（Ollama Cloud）|
| 思考强度 | high |
| 上下文窗口 / 最大输出 | 1,048,576 / 384,000 |
| 并发 | 2 |
| 轮次 | 每组 3 轮，共 18 次运行、360 题次 |
| 插件版本 | dsh-ops 0.5.5、tool-plus 0.3.0-beta.5 |
| 运行方式 | DSH 跑在实例容器内，改动直接落 `/testbed`，`git diff --cached` 即补丁 |
| 判分 | 官方 harness `swebench.harness.run_evaluation` |

各组工具面构成：

| 工具类别 | 官方工具面 · 标准（18 个） | dsh-ops · 标准（19 个） | tool-plus · 标准（17 个） |
|---|---|---|---|
| 命令执行 | bash | bash | bash |
| 读文件 | read、read_image | ops_inspect_local_file、read_image | read |
| 搜索 | glob、grep | ops_glob、ops_grep | glob、grep |
| 写 / 改 | write、edit | write、edit | write、edit |
| 后台任务 | job_list、job_output、job_kill | 同左 | 同左 |
| 子代理与消息 | 已禁用 | 已禁用 | 已禁用 |
| 目标与笔记 | create_goal、get_goal、update_goal、todo_write | 同左 | 同左 |
| 网络 / 技能 / 工作流 | web_fetch、skill、workflow、working_directory | 同左 | 同左 |
| 工具发现 | — | ops_discover_tools | — |

- **dsh-ops 0.5.5**：读文件、搜索三件换成 `ops_inspect_local_file`/`ops_glob`/`ops_grep`，另加 `ops_discover_tools`；`bash` 与其余宿主工具保持原生。
- **tool-plus 0.3.0-beta.5**：工具名基本不变，实现由插件接管；不暴露 `read_image`，工具数比官方标准少 1。
- **三个 PTC 组**：对外只暴露 1 个 `run_code`，上表工具在代码块内可调用。
- **子代理**：五种子代理与消息工具在六组模板中全部禁用。

口径：

- 步数 = 实际请求次数；工具调用 = `tool/call` 事件数，时长取 `tool/call` 到对应 `tool/result` 的墙钟，同一步并行调用取区间并集。
- token 取上游 usage 精确值：**输入** = 未命中缓存部分，**缓存读** = 命中部分，**输出** = 含思考。`totalTokens` 是每步上下文量不是累计值，总 token 按输入 + 缓存读 + 输出逐题求和。
- **LLM 响应时间** = 各步时长之和 − 同一步工具调用区间并集；**除 LLM 响应外的耗时 = 墙钟 − LLM 响应**。
- 墙钟取驱动记录的 `agent_sec`；三轮合计值用于横向比较，单轮波动另列。

### 5.2 系统提示词与工具定义

系统提示词与工具定义每步重发一次，「单步固定开销 × 步数」就是它在一次运行里被重复计费的总额。

| 组 | 暴露工具数 | 系统提示词 token | 工具定义 token | 单步固定开销 | 固定开销合计/题 | 占总 token | 除固定开销外 token/题 |
|---|---|---|---|---|---|---|---|
| 官方工具面 · 标准 | 18 | 449 | 3,267 | 3,716 | 83,982 | 12.2% | 604,032 |
| 官方工具面 · PTC | 1 | 5,163 | 514 | 5,677 | 132,842 | 19.9% | 533,257 |
| dsh-ops · 标准 | 19 | 734 | 4,161 | 4,895 | 115,522 | 14.9% | 660,874 |
| dsh-ops · PTC | 1 | 5,163 | 514 | 5,677 | 139,654 | 19.2% | 586,272 |
| tool-plus · 标准 | 17 | 466 | 3,835 | 4,301 | 111,826 | 15.9% | 590,620 |
| tool-plus · PTC | 1 | 5,711 | 514 | 6,225 | 166,208 | 24.0% | 526,673 |

`单步固定开销 = 系统提示词 token + 工具定义 token`；`固定开销合计/题 = 单步固定开销 × 步/题`；`除固定开销外 token/题 = 总 token/题 − 固定开销合计/题`。PTC 的固定开销占比高于标准模式。

## 7 行为分析

### 7.1 标准模式：回吐越细，往返越多

工具调用构成（次/题，同类工具已合并）：

| tool-plus · 标准 | 19.3 | 5.2 | 1.1 | 4.8 | 0.5 | 3.3 | 34.4 |

单步特征：

| 组 | 步/题 | 调用/步 | 输入 token/步 | 每步回吐 token | 工具秒/次 | LLM 秒/步 |
|---|---|---|---|---|---|---|

### 7.2 PTC 模式：一次代码块干多件事

| 组 | 步/题 | 代码块/题 | 输入 token/步 | 每步回吐 token | 单次执行（毫秒）| LLM 秒/步 |

三个 PTC 组中，dsh-ops 的代码块更多、单次执行更慢；tool-plus 的代码块最多、单次执行最快，单步回吐最低，但 LLM 秒/步高于 dsh-ops，墙钟与总 token 均高于官方 PTC。

### 7.3 步数不是效率指标

| 观察 | 数值 | 说明 |
|---|---|---|
| 完整组步数最多 | tool-plus · PTC 26.7 | 墙钟 153 s、总 token 692,881/题 |
| 完整组步数最少 | 官方工具面 · 标准 22.6 | 墙钟 156 s、总 token 688,014/题 |
| 标准组 bash 最快 | tool-plus · 标准 2,342 ms | 官方 · 标准 3,528 ms、dsh-ops · 标准 3,604 ms |
| PTC 外层执行最慢 | dsh-ops · PTC 3,764 ms | 官方 · PTC 2,591 ms |

步数只反映往返次数，不反映单次执行成本与回吐量。

### 8.5 同类工具的差异

- **命令执行**：官方 `bash` 平均 3,528 ms、dsh-ops 3,604 ms、tool-plus 2,342 ms；调用次数分别为 1,286、1,099、1,159。
- **读文件**：官方 `read` 平均 16 ms、每次回吐 1,511 token；dsh-ops `ops_inspect_local_file` 平均 30 ms、每次回吐 1,433 token；tool-plus `read` 平均 24 ms、每次回吐 821 token。
- **搜索内容**：官方 `grep` 平均 49 ms、每次回吐 1,038 token；dsh-ops `ops_grep` 平均 232 ms、每次回吐 1,299 token；tool-plus `grep` 平均 61 ms、每次回吐 1,067 token。
- **搜索文件名**：官方 `glob` 平均 86 ms，dsh-ops `ops_glob` 平均 138 ms，tool-plus `glob` 平均 39 ms。
- **网络读取**：官方 `web_fetch` 183 次、平均 604 ms；dsh-ops 167 次、平均 518 ms；tool-plus 193 次、平均 505 ms。
- **后台等待**：tool-plus `job_output` 23 次，共 1,729.8 s，平均 75,209 ms/次；官方 13 次共 321.4 s，dsh-ops 8 次共 72.8 s。等待的是真实后台任务。
- **PTC**：外层 `run_code` 平均响应官方 2,591 ms、tool-plus 2,307 ms、dsh-ops 3,764 ms；失败率官方 2.21%、dsh-ops 2.38%、tool-plus 2.71%。
